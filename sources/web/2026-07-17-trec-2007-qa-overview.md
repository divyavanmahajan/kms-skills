# TREC 2007 QA Track overview — summary notes (nugget methodology points)

Brief notes captured for the nugget-evaluation lineage; only the
nugget-methodology facts are recorded here (source consulted via search
excerpts, not read in full — thin snapshot, expand on next touch).

- The nugget evaluation methodology entered the TREC QA Track in 2003 for
  free-form **definition questions**: the assessor creates a list of
  "information nuggets" — a fact for which the assessor can make a binary
  decision as to whether a response contains it — and decides which are
  **vital**; the assessor then marks which nuggets appear in each system
  answer.
- **Nugget pyramids** (introduced as a refinement, applied in TREC 2006)
  combine judgments of nugget importance from **multiple assessors**,
  increasing the stability and discriminative power of the evaluation at
  small additional assessment cost.
- Based on that success, the nugget pyramid method became the **official
  evaluation method for "Other" questions in TREC 2007**.
